# Модуль Checkbox ПРРО для OkayCMS

Модуль інтегрує програмну касу [Checkbox](https://checkbox.ua) з OkayCMS: дозволяє створювати фіскальні чеки та чеки повернення, керувати змінами касира, налаштовувати податкові групи й автоматично фіскалізувати замовлення при зміні статусу або після отримання посилки Новою Поштою.

## Можливості

### Фіскальні чеки

- Створення чека продажу для замовлення.
- Створення чека повернення.
- Перегляд усіх чеків замовлення прямо в адмінці.
- Посилання на чек для покупця на сторінці замовлення.
- Чек покупцеві на email або на телефон (Viber, а якщо не дійде — SMS).

### Оплата частинами (передплата)

- Чек авансу, коли клієнт вносить частину суми.
- Чек післяплати на решту — Checkbox сам рахує залишок.
- Аванс і решта можуть надійти різними способами (наприклад переказ на рахунок,
  а решта через інтегратора при отриманні): джерело коштів обирається окремо для
  кожного чека, і саме воно визначає засіб платежу в чеку.
- Повернення всієї оплати одним рухом: Checkbox створює чек повернення на кожен
  виданий чек.
- Стан оплати видно в картці замовлення, з підказкою, що робити далі.

### Зміни касира

- Відкриття та закриття зміни касира.
- Перегляд журналу змін із статусами та датами.
- Автоматична перевірка та закриття застарілих змін.

### Податкові групи

- Довільні податкові групи (код + назва) для передачі до Checkbox.
- Призначення податкової групи кожному товару окремо.

### Автоматизація

- Автоматичне створення чека при переході замовлення у вказаний статус: замовлення стає оплаченим, зміна відкривається сама.
- Автоматичне створення чека при отриманні посилки Новою Поштою (потребує модуля [Нова Пошта](https://github.com/devSviat/NovaPoshta-OkayCMS) або старого [NovaPoshtaTracking](https://github.com/devSviat/NovaPoshtaTracking-OkayCMS)).
- Cron-завдання запускаються через вбудований планувальник OkayCMS.

### Налаштування способів оплати

- Для кожного способу оплати задається тип Checkbox (`CASH`, `CARD`, `CASHLESS`, `OTHER`).
- Можна повністю відключити фіскалізацію для обраного способу оплати.

## Вимоги

- Перевірено на PHP 8.5
- OkayCMS 4.5.3 (чиста або [форк](https://github.com/devSviat/OkayCMS-Fork))
- Обліковий запис касира на [my.checkbox.ua](https://my.checkbox.ua) (логін, пароль, ліцензійний ключ каси)
- Модуль [**Нова Пошта**](https://github.com/devSviat/NovaPoshta-OkayCMS) або старий [**NovaPoshtaTracking**](https://github.com/devSviat/NovaPoshtaTracking-OkayCMS) (опціонально — для автоматичної фіскалізації при отриманні Новою Поштою). Поки встановлені обидва, чеки йдуть на посилки з обох; модуль Нова Пошта рахує отримання за датою статусу НП, тож перенесені давні посилки чеків не отримають.

## Встановлення

### Варіант 1: Скачування з GitHub

1. Скачайте останню версію модуля з [останнього релізу на GitHub](https://github.com/devSviat/Checkbox-OkayCMS/releases/latest).
2. Розпакуйте архів на сервері в каталог: `{OkayCMS_root}/Okay/Modules/`

### Варіант 2: Встановлення через Git

1. Виконайте команду в директорії `{OkayCMS_root}/Okay/Modules/Sviat`:
   ```bash
   git clone https://github.com/devSviat/Checkbox-OkayCMS.git Checkbox
   ```

### Результат встановлення

Шлях до модуля має бути таким:
```bash
{OkayCMS_root}/Okay/Modules/Sviat/Checkbox/
```

Після встановлення перейдіть в адмін-панель → Модулі → Знайдіть «Checkbox» → Натисніть «Встановити».

## Налаштування і використання

### Підключення до Checkbox

1. Перейдіть в адмін-панель → Checkbox ПРРО → Налаштування.
2. Заповніть облікові дані касира:
   - **Логін** — логін касира з my.checkbox.ua.
   - **Пароль** — пароль касира.
   - **Ліцензійний ключ каси** — знаходиться в розділі «Каси» → «Дії» → «Деталі» в особистому кабінеті Checkbox.
3. Збережіть налаштування.

### Фіскалізація чеків

- Відкрийте потрібне замовлення в адмінці.
- Натисніть «Фіскалізувати чек» для створення чека продажу.
- Натисніть «Створити чек повернення» за потреби.

### Оплата частинами

1. Відкрийте замовлення й натисніть «Виставити чек авансу».
2. Вкажіть суму авансу й оберіть, звідки надійшли кошти — назва джерела
   друкується в чеку як засіб платежу.
3. Коли надійде решта, натисніть «Закрити чеком післяплати» й оберіть, як саме
   вона надійшла. Суму рахує Checkbox — вводити її не треба.

Аванс мусить бути меншим за вартість товарів: рівна сума — це звичайний продаж.
Поки оплата не закрита, звичайний чек продажу на це замовлення не виставляється,
щоб не задвоїти фіскалізацію.

Якщо в замовлення відкрита оплата частинами, а ви створюєте накладну Новою
Поштою, у формі підставляється **залишок**, а не повна сума: те саме поле задає
і контроль оплати, і накладений платіж.

### Автоматичне створення чеків при зміні статусу

1. У налаштуваннях модуля на вкладці «Коли створюється чек» вкажіть статус.
2. Коли замовлення переводять у цей статус, вручну або масово зі списку, воно стає оплаченим, зміна відкривається сама і створюється чек.
3. Збереження замовлення без зміни статусу нічого не запускає. Щоб вимкнути, оберіть «Статус не вибраний».

### Автоматична фіскалізація при отриманні Новою Поштою

1. Встановіть та увімкніть модуль [**Нова Пошта**](https://github.com/devSviat/NovaPoshta-OkayCMS) (або старий [**NovaPoshtaTracking**](https://github.com/devSviat/NovaPoshtaTracking-OkayCMS)).
2. На вкладці «Коли створюється чек» оберіть «Створювати автоматично» для отриманих посилок.
3. Переконайтесь, що на сервері налаштовано cron-завдання (щохвилини):
   ```
   * * * * * php {OkayCMS_root}/ok scheduler:run
   ```
   Чеки будуть створюватися кожні 10 хвилин після оновлення статусу ТТН.

### Обов'язковий спосіб оплати в замовленні

Без способу оплати модуль не знає, якою формою фіскалізувати чек. Опція «Спосіб оплати обов'язковий у замовленні» в розділі Налаштування не дає менеджеру створити чи зберегти замовлення в адмінці, не обравши спосіб оплати:

- біля поля «Оплата» з'являється червона зірочка;
- форма без обраного способу не відправляється: під полем з'являється «Обов'язково», а менеджер бачить пояснення;
- якщо перевірку в браузері обійти, сервер теж нічого не запише й поверне на форму з помилкою.

Опція діє і на нові, і на наявні замовлення. Замовлення з вітрини вона не зачіпає.

### Куди надсилати чек покупцеві

На вкладці «Чек» оберіть, куди Checkbox надішле чек після фіскалізації:

- **Не надсилати.**
- **На email.**
- **На телефон (Viber або SMS).** Checkbox шле чек у Viber, а якщо він не дійде — SMS.
- **На email і на телефон.**
- **На email, а без email — на телефон.** Телефон потрібен лише для замовлень без пошти,
  тож платних повідомлень менше.

Налаштування діє на всі чеки замовлення: продаж, повернення, аванс і післяплату. За
замовлення з передплатою на телефон підуть два повідомлення.

Відправка на телефон платна. Її вмикають і поповнюють у кабінеті Checkbox. Поки її не
ввімкнено, Checkbox приймає номер і нічого не надсилає. Тому, коли вибрано режим із
телефоном, сторінка налаштувань перевіряє це в Checkbox і показує попередження.
Checkbox приймає лише українські номери (+380): покупець з іноземним номером отримає чек
тільки на email, якщо його вказано.

### Податкові групи

1. Перейдіть в Checkbox ПРРО → Податкові ставки.
2. Додайте групи з відповідними кодами (відповідно до налаштувань каси в Checkbox).
